# Franklinville Hardware

Modern marketing site for Franklinville Hardware, rebuilt with SvelteKit and Tailwind CSS.

## Stack

- SvelteKit
- Tailwind CSS
- Static adapter output in `build/`

## Local Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build
```

## Project Notes

- Route files live in `src/routes/`
- Shared UI components live in `src/lib/components/`
- Shared content and site data live in `src/lib/data/site.ts`
- Store photography is served from `static/`
